# Python Port Scanner

## What it is
A simple port scanner built in Python 
that scans a target IP address for 
open ports.

## What it does
- Takes an IP address as input
- Scans ports 1 to 1024
- Reports which ports are open
- Reports which ports are closed

## Tools used
- Python
- Socket library

## How to run it
1. Install Python
2. Run: python port_scanner.py
3. Enter target IP address
4. See results

## Results
When I tested it on my hotspot I found:
- Port 21 (FTP) is OPEN
- Port 58 (DNS) is OPEN
